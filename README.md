## How I work

- **Frame the decision:** define the question, audience, and success measure before choosing a method.
- **Validate the evidence:** document sources, assumptions, exclusions, and data quality checks.
- **Model with discipline:** separate development from evaluation and report useful error measures.
- **Communicate for action:** pair technical results with interactive explanations and practical limitations.
